# giftsie — customer-facing website (prototype)

Boutique gift shop in Union Station, Washington, DC, curating products from
independent makers across DC, Maryland & Virginia.

## Structure
- `index.html` — entire site (Home, Catalog, Gallery, Makers, My Story, About/Contact)
- `images/` — logo + wordmark; numbered placeholders in `images/placeholders/`
- `LAUNCH-GUIDE.md` — photo slot map, Shopify conversion, Ricochet integration, email setup

## Local preview
Open `index.html` in a browser — no build step required.

## Deploy (Vercel)
Static site: import the repo in Vercel, framework preset **Other**,
no build command, output directory = repo root.
