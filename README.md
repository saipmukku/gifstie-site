# giftsie — customer-facing website

Boutique gift shop in Union Station, Washington, DC, curating products from
independent makers across DC, Maryland & Virginia.

## Structure
- `index.html` — entire site (Home, Catalog, Gallery, Makers, My Story, About/Contact)
- `data/products.json` — **the live catalog feed**, generated by the sync job. Do not edit by hand.
- `sync/` — the Ricochet CSV → catalog pipeline (Node, no dependencies)
- `images/products/` — product photos, keyed by SKU. See the README in that folder.
- `images/` — logo + wordmark; placeholders in `images/placeholders/`
- `LAUNCH-GUIDE.md` — photo map, catalog sync, Meta analytics, email setup

## The catalog

The site is **browse-only** — it drives a visit to the shop, it does not sell online.
The catalog comes out of Ricochet as a CSV export and is published to the site by
the sync job:

```
Ricochet export (.csv)  →  node sync/sync.mjs  →  data/products.json  →  the site
```

To refresh the catalog:

```bash
node sync/sync.mjs --csv "~/Downloads/Products <timestamp>.csv"
node sync/sync.mjs --csv <file> --dry-run   # see what would change first
```

The job treats each export as the full authoritative snapshot: it validates the
columns, aborts rather than letting a truncated export empty the site, soft-deletes
SKUs that disappear instead of dropping them, and reports what changed.

**Browse axes.** Three come straight from the export and cannot be wrong — maker
(`Consignor`), price band (`Agreed Price`), and recent arrivals (the `In stock`
column, which is the intake date). The fourth, category, is derived from product
names by the ruleset in `sync/categories.json` because Ricochet's own `Category`
field is populated on ~1% of rows. A real `Category` value always wins, so filling
it in Ricochet retires the ruleset incrementally.

**Photos never travel through the CSV.** They live in `images/products/<SKU>.<ext>`
and are joined by SKU at sync time. Items without a photo render a line-art glyph
for their category. See `images/products/README.md`.

## Integrations
Configured in `SITE_CONFIG` at the top of the `<script>` block in `index.html`:
- **Catalog:** reads `data/products.json`. If a Shopify store is ever connected
  (`shopifyDomain` + `storefrontToken`), the Storefront API takes priority and the
  static feed becomes the fallback — the page supports both, no rewrite needed.
- **Meta Pixel:** set `metaPixelId` to enable PageView / Lead tracking.

Setup steps: see `LAUNCH-GUIDE.md`.
